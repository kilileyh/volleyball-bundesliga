# Winners vs. Losers in the German Volleyball Bundesliga

## Research Question
How do winners and losers differ in serving, receiving, attacking, and blocking statistics within the same German volleyball match, and do these differences vary between men's and women's leagues?

## Data
Match statistics of the German Volleyball Bundesliga (men and women), seasons 2013/14 to 2018/19, from the [volleystat](https://github.com/bozhinvi/volleystat) R package (CC0 license).

## Project Structure
- `data/raw/`: original `.rda` files
- `data/processed/`: cleaned data (generated, not tracked by Git)
- `src/`: Python scripts
- `notebooks/`: exploration
